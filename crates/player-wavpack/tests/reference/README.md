These files were made by the reference `wavpack` 5.9.0 command-line encoder (`.wv`), decoded by its `wvunpack`
(`.decoded.raw`), and described by `wvunpack -ss` (`.ss.txt`). They come from the fixtures of the `wavicle` crate
(MIT OR Apache-2.0, https://github.com/mark-ik/wavicle), which generated them from deterministic tones, ramps and
silence. They are used only as test data: `tests/reference_files.rs`.
