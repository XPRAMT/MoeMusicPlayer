# MoeMusicPlayer

MoeMusicPlayer 是以本機優先為設計方向的 Windows 與 Android 音樂庫。使用者偏好與已登錄來源路徑保存在有版本的 `settings.json`；曲目、播放清單內容、來源映射、掃描狀態、播放 session 檢查點與累計播放時長保存在 SQLite。介面以分頁載入曲目，不會把整個曲庫一次送到前端。

## 功能

- 使用 Windows 原生資料夾選擇器加入音樂資料夾並在背景增量掃描；取消不會新增來源。
- Android 可透過 MediaStore 選擇共享音樂儲存空間，或用系統文件選擇器（SAF）選擇資料夾；播放使用 Media3，切到背景後由前景媒體服務持續播放。
- 來源暫時不可用或掃描未完成時，保留先前已索引的曲目。
- 以分頁結果瀏覽及搜尋已保存曲庫；介面不會載入整個曲庫。頂欄顯示目前頁的中文標題。來源同步狀態只出現在「設定 → 音樂來源」。視窗標題含編譯日期，例如 `MoeMusicPlayer 26.10.8`。
- 曲庫與播放清單共用資訊欄順序及顯示設定。序號固定。列表不再顯示播放按鈕。點擊曲庫、播放清單或播放佇列任一列會立刻開始播放，暫停中也一樣。播放佇列的點擊只改目前播放位置，不會重建佇列。標籤沒有曲名或只有空白時，這些列表、正在播放頂列與底部播放列改顯示檔名（不含資料夾與副檔名）；尚未對應且沒有曲名的播放清單項目也一樣。
- 播放頁的「快速設定」與「設定」使用同一組分頁與控件。抽屜背景預設 70% 不透明，可在「設定 → 外觀」調整。「正在播放」預設封面在前、歌詞在後，可在「設定 → 播放頁」或快速設定選擇 A/B 排列。兩處都能調整背景模糊與「封面背景亮度」；播放頁底色固定全透明。頂列曲名是純文字。演出者若以 `|`、`\`、`/`、`;`、`,` 或空白分隔（例如 `hanser/yousa`），會分別顯示並可點擊，曲庫只篩選被點到的那位；專輯仍依完整值篩選。音訊格式、播放次數與 Hi-Res 標誌顯示在其下方（播放次數字體與音質文字一致）。封面維持原始比例、無邊緣細框，圖片下方不再放文字。頂列「手動指定」可開啟歌詞候選選擇，「同步歌詞」可調整同步延遲（±5 秒）。播放頁開啟時，底部曲名與演出者按鈕會返回進入前頁面。底欄除了播放控件、音量和進度條，點空白處也能開關播放頁，進度列橫跨整個控制列上方。亮色封面上的歌詞文字加深色陰影以維持對比。音訊格式各欄以全形點號「．」分隔；歌詞文字置中，A/B 切換、譯文／羅馬拼音、文字透明度與字級、句間距等偏好仍可在抽屜調整並保存。來源音訊達 48 kHz 以上且 24-bit 以上時才顯示 Hi-Res 標誌。
- 可在「設定」自訂背景色與主色，偏好保存在 `settings.json`，文字顏色會依背景自動調整對比。「設定 → 外觀」也可選擇主介面背景圖片，選取後會複製到 `UserData/background`。模糊（0–40 px）與亮度（0–100）的做法與播放頁封面背景相同，且不會改到播放頁。
- 若設定檔與備份都無法復原，來源同步會暫停，直到重新登記並確認預期來源；已索引曲目仍會保留。
- Windows 資料夾與播放清單掃描會排除 `.mp4` 影片候選，並保留 `.m4a`、`.aac` 音訊候選。
- Windows 可播放本機 WAV、MP3、FLAC 與 Ogg Vorbis，並提供播放/暫停、跳轉與音量控制。
- Windows 可在「設定 → 輸出」選擇曲目取樣率與輸出裝置不同時的轉換方式：「高品質」（預設）維持裝置混音取樣率，由 rubato 的 FFT 進行取樣率轉換（區塊大小 2048）。濾波範圍依來源與輸出取樣率自動調整；取樣率相同時直接輸出。「Windows 內建」以曲目取樣率開啟輸出交由 Windows 轉換，前後曲目取樣率不同時換曲可能短暫停頓。兩者皆為共享模式，並非 bit-perfect。同一頁可開啟 DSEE HX：需先安裝 Sony Music Center，播放器只從 `C:\Program Files (x86)\Sony\Music Center\Sony.Earth\OmgDseeHxFilter.ax` 載入、不附帶該檔。48 kHz 以下的雙聲道都會處理，不看位深；高於 48 kHz 不處理。48 kHz 系列輸出 96 kHz／24-bit，44.1 kHz 系列輸出 176.4 kHz／24-bit。有損格式送進濾鏡前轉成 32-bit PCM，無損格式保持原來的位深。分頁會顯示目前轉換狀態，例如「44.1 kHz → 96 kHz（高品質）」或「48 kHz → 96 kHz（DSEE HX）」。
- Windows 正在播放時優先顯示曲目內嵌封面，再依序尋找同資料夾的 `cover.jpg`、`folder.jpg`；「正在播放」頁與底部播放列共用原始圖片資料。Android 封面透過二進位 IPC 使用原始內嵌圖片位元組。
- 「正在播放」會優先讀取授權來源中的本機 LRC 檔與內嵌歌詞；缺少時可搜尋網易雲、QQ 歌詞候選。若有逐行時間便同步高亮；只會自動套用高信心匹配，也可手動選取並保存候選。歌詞候選面板把「搜尋」「關閉」「移除歌詞」放在右側：搜尋框空白時用目前曲目再搜，關閉只收起面板，移除歌詞會解除已套用關聯並關閉面板。同名 LRC 與檔案內嵌歌詞也在清單中，選取後以手動指定保存。歌詞會朝獨立捲動視窗上下邊緣逐漸淡出，目前句維持置中；同步播放時會平滑跟隨相鄰歌詞。「快速設定」與「設定 → 歌詞」共用已保存偏好，可控制譯文／羅馬拼音、非目前歌詞文字透明度、原文與輔助文字字級、歌詞句間距，以及簡體轉繁體。簡轉繁只使用 OpenCC 字形字典（`STCharacters`、`STPhrases`、`TWVariants`；MIT／Apache-2.0，見 `licenses/`），播放時在記憶體轉換整首歌，不另存繁體歌詞，也不把「软件」改成「軟體」。
- Windows 與 Android 可匯入與匯出 M3U、UTF-8 M3U8 播放清單；Android 以持久 SAF 樹授權存取播放清單，且相對項目只會在授權樹內解析。新匯入的播放清單檔案會登錄為來源，舊有靜態清單不會被猜測連結到某個檔案。尚未對應曲庫的項目會保留，相對路徑匯出限於所選共同根目錄內。
- Windows 與 Android 提供佇列前後首、隨機與循環關閉／全部／單曲模式；播放清單佇列會保留重複項目。只有音訊處於 Playing 且播放位置自然前進時才累計聆聽時間。新生成的隨機 traversal 會提高 `played_ms / duration_ms` 比值較低曲目的抽中機率；未知或 0 時長採中性權重；現有 traversal 不會在播放中重新排列。
- Windows 系統媒體控制會廣播目前曲名、演出者、專輯、封面、播放狀態與時間軸；播放／暫停／停止／跳轉及可用時的佇列前後首會送回音訊服務處理。Android 透過 MediaSession 通知與背景服務提供媒體控制及佇列導覽。

Android Media3 播放整合已完成，ARM64 APK 已安裝至 NX809J 並成功啟動；曲庫顯示 207 首，封面與歌詞畫面可呈現。實際聲音輸出、播放控制、背景行為、SAF 存取及歌詞讀取仍待人工驗收；目前一個文件資料夾來源回報暫不可用，原因待確認。

## 在 Windows 執行

1. 安裝 Node.js 20.19+（或 22.12+）、Rust 1.90+，以及 [Tauri 先決條件](https://v2.tauri.app/start/prerequisites/)。
2. 執行 `npm install`。
3. 執行 `npm run tauri -- dev`。
4. 開啟「設定 → 音樂來源」，選擇「選擇資料夾並同步」，再選取現有音樂資料夾；取消不會變更來源清單。
5. 開啟「設定 → 外觀」選擇背景色與主色；預設為純黑背景與水藍主色。在「設定 → 曲目欄位」可調整曲庫與播放清單共用欄位的順序及顯示狀態。在「設定 → 播放頁」選擇 A/B 排列，並調整封面背景模糊與「封面背景亮度」；播放頁元件底色固定全透明。在「設定 → 快捷鍵」可改全螢幕、播放／暫停、5 秒進退與上下一首，也可綁定手柄按鈕與搖桿方向；預設是 F11、空白鍵、左右方向鍵與滾輪、Page Up／Page Down 與滑鼠側鍵，不含手柄。偏好與來源路徑保存在 App 資料目錄的 `settings.json`，SQLite 保存音樂資料、播放 session 檢查點與累計播放時長。

Windows 會將設定與 SQLite 資料保存在目前執行檔旁的 `UserData` 資料夾。固定版請讓 `release/UserData/` 與 `release/moemusicplayer.exe` 放在一起；只移動執行檔會使用另一份空曲庫。Windows 不會回退使用 Roaming 或 LocalCache，也不會自動搬移不同位置的資料。Android 仍使用平台管理的 App 資料目錄。

建置 Windows 執行檔請執行 `npm run release:windows`。命令一律使用 repo 的 `target` 目錄建置，不受呼叫端的 `CARGO_TARGET_DIR` 影響，產物固定在 `release/moemusicplayer.exe`。建置失敗會保留先前版本。

## 建置 Android 版

安裝 Android SDK、NDK 與 Java 21，再執行：

```sh
npm install
npm run android:build:arm64
```

Debug APK 輸出至 `src-tauri/gen/android/app/build/outputs/apk/universal/debug/app-universal-debug.apk`。驗證後的固定複本為 `release/moemusicplayer-android-arm64-debug.apk`。在裝置上開啟「設定 → 音樂來源」，授權 MediaStore 或選擇 SAF 資料夾。匯入播放清單時需授權其所在 SAF 樹。播放由前景 MediaSession 服務維持背景控制，下一次啟動會還原保存的佇列並保持暫停。使用者偏好與來源註冊保存在 App 資料目錄的 `settings.json`，曲庫及播放 session 資料保存在 SQLite。
