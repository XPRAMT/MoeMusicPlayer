# MoeMusicPlayer

**適用於 Windows 與 Android 的簡單、極速、專業的本機音樂播放器。** 音樂留在你自己的裝置上：加入資料夾或 M3U/M3U8 播放清單，MoeMusicPlayer 就會建立可搜尋的曲庫，不需要任何線上帳號。

> **原始碼公開，不是開源。** 原始碼公開，可在非商業用途下自由使用與修改，但禁止商業使用。詳見[授權](#授權)。

## 特點

- **簡單：** 加入資料夾、按下播放就能用。清單、搜尋、排序與播放清單都照你預期的方式運作，播放頁左右並排顯示封面與歌詞，所有設定都在同一個地方。
- **極速：** 大型曲庫以分頁並虛擬化的清單瀏覽，數千首歌也能流暢捲動。掃描以多執行緒讀取標籤：5,400 首的曲庫從零建立約 5 秒（檔案已在系統快取時；第一次從冷磁碟讀取則取決於你的硬碟速度）。掃描中關閉視窗會保存已讀到的進度，下次從中斷處繼續。
- **專業：** 可直接編輯標籤與封面、檢視頻譜圖、播放 DSD；在 Windows 還能用 WASAPI 獨佔模式位元完美輸出，或同時輸出到多台裝置。
- **自動抓歌詞：** 播放器會替你找歌詞。先讀本機 `.lrc` 或內嵌歌詞；都沒有時會搜尋網易雲與 QQ，只有在標題高度吻合、時長相差不超過 2 秒、而且是同步歌詞時才會自動套用。你隨時可以手動搜尋、改選其他結果或重新載入，手動選過的歌詞不會被自動結果覆蓋。

## Windows 與 Android 共通功能

- **音樂來源：** 加入資料夾與 M3U/M3U8 播放清單、排除資料夾；來源暫時無法使用或掃描未完成時，會保留先前已索引的曲目。影片不會加入曲庫。
- **遠端曲庫（SMB）：** 可加入 SMB 伺服器上的音樂資料夾與 `.m3u`／`.m3u8` 播放清單（設定 → 音樂來源，每台伺服器一個分頁；密碼在裝置上加密保存）。歌曲直接從伺服器經磁碟快取（0.1–5 GB，在設定 → 音樂來源調整）播放，封面、歌詞與標籤也從伺服器讀取，伺服器上的歌曲可在歌曲資訊面板開啟並編輯；收藏鈕可在伺服器上的播放清單檔加入或移除歌曲，沿用檔案原本的路徑寫法並保留一份舊版 `.bak`。同一個檔案經由多個來源（同一台伺服器上的播放清單與資料夾）到達時只算一首，不會重複。頂欄的開關可只顯示本地歌曲、全部或只顯示遠端歌曲。掃描很快：掃描 SMB 伺服器上的曲庫時只讀每個檔案的標籤與音訊屬性，不讀封面圖片。FLAC 把圖片放在長度已知的獨立區塊，讀取器直接跳過，每首約 32 KiB、2 個小請求；MP3、M4A、DSF、Opus 的圖片在標籤結構內，必須把整張封面讀完才能丟棄，封面很大時這些格式經網路掃描會比較慢，所以遠端曲庫最適合使用 FLAC。SMB 用戶端使用自己的傳輸層（`TCP_NODELAY`、每個封包只寫一次），消除了每次往返約 45 ms 的停頓（在作者的環境中，閒置請求由約 187 ms 降到約 4.5 ms）；在作者的 NAS 上，5,335 首（多為 FLAC）的曲庫完整掃描：檔案在伺服器快取中時（重複掃描）約 10 秒；第一次、NAS 要從硬碟讀標籤時約 5 到 50 秒，差異主要看硬碟要尋址到哪些檔案。實際結果取決於你的伺服器、硬碟與網路。之後的掃描只重讀新增或變更的檔案（大小與修改時間未變的檔案會略過）。
- **曲庫與播放清單：** 分頁清單，支援搜尋、欄位排序、調整欄位順序與顯示、自然數字排序（Track 2 排在 Track 10 前），以及分組標題與快速查找。點擊歌曲列即可播放，拖曳播放佇列的歌曲列可調整順序。欄位含來源（本地或伺服器名稱）與檔案修改時間；演出者與專輯索引會列出曲目數與累計播放時長；48 kHz／24 bit 以上會顯示 Hi-Res 標誌。
- **播放控制：** 隨機播放（依聆聽時長加權）、上一首／下一首、循環關閉／全部／單曲、重啟後接續播放、睡眠定時，以及觸控螢幕手勢（在封面或歌詞上左右滑動切到下一首或上一首）。
- **正在播放：** 排列 A（左封面右歌詞）或 B；封面可縮放 0.5 到 10 倍；可調整歌詞字級、行距、陰影或描邊、譯文與羅馬拼音、簡體歌詞轉繁體顯示，以及每首歌各自的同步延遲。
- **歌曲資訊與標籤編輯：** 播放頁頂欄的資訊按鈕可查看路徑與音訊屬性，並編輯標題、演出者、專輯、專輯演出者、作曲、類型、日期、音軌／碟號、內嵌歌詞與一張封面（取代、貼上、匯出、複製或移除）。按「儲存」才會寫入檔案；「導入」可把使用中的歌詞存進檔案。
- **頻譜圖：** FFT 頻譜圖，可選配色、窗函數、FFT 大小與 dB 範圍，支援雙指縮放或滾輪縮放。Windows 以獨立視窗開啟，Android 為全螢幕頁。
- **DSD：** `.dsf` 檔轉成 176.4 kHz PCM 播放，增益可調。Windows 另有 352.8 kHz 輸出與 DoP（見下）。
- **外觀與語言：** 背景與主色；主介面背景有五種模式：純色、單張圖片、幻燈片、專輯封面與系統桌布（Android 的系統桌布需要開啟「所有檔案存取權」）；自動文字顏色或自動圖片透明度。介面語言有繁體中文、简体中文、日本語與 English（設定 → 主介面 → 語言）。
- **備份與還原：**「設定 → 關於 → 備份與還原」可把你勾選的內容（曲庫、設定、以密碼保護的伺服器帳號、我的最愛，不含專輯封面）匯出成一個壓縮檔，也可匯入這個壓縮檔或其中的單一檔案（`settings.json`、曲庫資料庫、`MyLove.m3u8`）。匯入會在下次啟動時套用，原本的資料會保留在 `before-import` 資料夾。
- **更新：** 播放器會檢查 GitHub 最新版本並提示更新（見[安裝](#安裝)）。「設定 → 關於」顯示建置資訊與使用的開源套件。

## Windows 與 Android 的功能差異

| | Windows（x64） | Android（arm64） |
|---|---|---|
| 格式 | WAV、MP3、FLAC、AAC/M4A、Ogg Vorbis、Ogg Opus、WavPack（`.wv`，無損與 hybrid，可搭配 `.wvc`；也支援 DSD-in-WavPack）、DSD（`.dsf`）、Matroska 音訊（`.mka`） | 依 Android 媒體框架可播放的格式，另由程式自己的解碼器播放 WavPack 與 DSD（`.dsf`） |
| 輸出 | 共享模式、**WASAPI 獨佔模式**（位元完美）、DSD 的 **DoP**、**同時輸出到多台裝置**（各自有音量、延遲與聲道映射） | 系統音訊輸出 |
| DSEE HX 升頻 | 選用（需 Sony Music Center；本專案不含其濾鏡） | 無 |
| 歌詞顯示 | 歌詞頁**與工作列歌詞** | 歌詞頁 |
| 系統整合 | 系統媒體控制、從檔案總管開啟音檔、可設為預設應用程式 | 媒體通知與鎖定畫面控制、背景播放 |
| 音樂來源 | 任意位置的資料夾與播放清單、SMB 伺服器，背景掃描 | 開啟「所有檔案存取權」後，以實際路徑加入資料夾與播放清單 |
| 頻譜圖 | 獨立視窗，可 A/B 比較兩個檔案 | 全螢幕頁 |
| 資料位置 | 執行檔旁的 `UserData` 資料夾（便攜） | 應用程式的私有資料夾 |
| 更新 | 忽略、自動安裝（下次啟動生效）或自動安裝並重啟 | 下載並交給系統安裝程式安裝 |

## 安裝

### Windows

需要 64 位元的 Windows 10 或 11，以及 Microsoft Edge WebView2 Runtime（Windows 11 與多數已更新的 Windows 10 內建）。

1. 如果安裝過 26.10.21 以前的版本，請先解除安裝：這一版改用不同的簽章金鑰，Android 不允許跨金鑰更新（解除安裝會清除 App 資料，請先到「設定 → 關於」匯出備份）。然後從[最新版本](https://github.com/XPRAMT/MoeMusicPlayer/releases/latest)下載 `moemusicplayer-windows-x86_64.zip`。
2. 把 `moemusicplayer.exe` 解壓縮到任一個你有寫入權限的資料夾（例如 `D:\MoeMusicPlayer`）並執行。程式是便攜版：`settings.json` 與曲庫放在執行檔旁的 `UserData` 資料夾，把執行檔移到其他資料夾會使用另一份全新的資料。
3. 開啟「設定 → 音樂來源」，加入資料夾或播放清單，曲庫會在背景建立。
4. 選用：若要從檔案總管開啟音樂檔，先在「設定 → 關於」登錄音訊格式（**登錄音訊格式**），再到 Windows「預設應用程式」選擇 MoeMusicPlayer。

更新：啟動時播放器會檢查最新版本，提供「忽略」（同一版本不再提示，除非你在「設定 → 關於」手動檢查更新）、「自動安裝」（下次啟動時生效）與「自動安裝並重啟」。`UserData` 不會被動到。

### Android

需要 Android 7.0 以上、64 位元（arm64）的手機或平板。

1. 從[最新版本](https://github.com/XPRAMT/MoeMusicPlayer/releases/latest)下載 `moemusicplayer-android-arm64.apk` 並開啟。Android 會要求允許瀏覽器或檔案管理員安裝不明應用程式，允許一次後確認安裝即可。
2. 開啟應用程式，到「設定 → 音樂來源」，為 MoeMusicPlayer 開啟「所有檔案存取權」（會帶你到系統設定頁），再加入資料夾或播放清單。
3. Android 13 以上請允許通知，媒體通知與鎖定畫面控制才會出現。

更新：應用程式會檢查同一個版本頁面。按「下載並安裝」後會驗證檔案並交給系統安裝程式；第一次系統會要求允許 MoeMusicPlayer 安裝不明應用程式。

若要提供 Codex 可讀的診斷報告，請在 Windows 的終端機執行 `moemusicplayer.exe --diagnostics-json`。JSON 會包含建置與程序資訊、上次啟動時的資料庫／音訊狀態、檔案大小及最近的 panic 記錄；不包含音樂標籤、設定內容或 SQLite 資料列。報告仍會包含本機執行檔與資料路徑，分享前請先檢查。

## 在 Windows 開發

安裝 Node.js 20.19+（或 22.12+）、Rust 1.90+ 與 [Tauri 先決條件](https://v2.tauri.app/start/prerequisites/)，再執行：

```sh
npm install
npm run tauri -- dev
```

建置 Windows 便攜版執行檔：

```sh
npm run release:windows
```

執行前端檢查與 Rust 工作區測試：`npm run check`、`cargo test --workspace --locked --offline`。

固定輸出為 `release/moemusicplayer.exe`，請與 `release/UserData/` 放在一起。發布用 zip 會打包到 `release/update-assets/`；打包不會發布版本。更新只用版本號（建置日期，tag 例如 `v26.10.21`）辨識，所以一天最多發布一版。

## 建置 Android 版

安裝 Android SDK、NDK 與 Java 21，再執行：

```sh
npm install
npm run android:build:arm64:release
```

這會建置最小的 release APK（約 30 MB）與給 Google Play 的 AAB，並複製到 `release/moemusicplayer-android-arm64-release.apk` 與 `.aab`。兩者都以環境變數 `MOE_ANDROID_KEYSTORE`、`MOE_ANDROID_KEY_ALIAS`、`MOE_ANDROID_KEYSTORE_PASSWORD` 指定的 release 金鑰簽章（沒有金鑰時使用 debug 金鑰）；版本碼為建置日期的數字。`npm run android:build:arm64` 會建置較大的 debug APK，可用 WebView 偵錯檢視。安裝後到「設定 → 音樂來源」開啟「所有檔案存取權」，再加入資料夾或播放清單。`npm run release:android` 會輸出 `release/update-assets/moemusicplayer-android-arm64.apk`，只有加上 `-Upload -ReleaseTag <tag>` 才會發布。
