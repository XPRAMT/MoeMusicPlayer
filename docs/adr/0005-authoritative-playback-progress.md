# Authoritative playback progress and seek drafts

The audio worker snapshot is the only playhead authority outside an active user gesture. The progress control may show a local draft while dragging, but it commits once on a native range `change` or pointer release, discards on cancellation or track change, and immediately returns to the latest snapshot after commit or error; stale polls started before a seek are fenced from overwriting its ACK. Display duration may fall back to the active track's stored metadata when Rodio reports `Source::total_duration() == None`, but this fallback does not claim the decoder supports seeking: failed seek IPC preserves the snapshot and reports an error. This avoids keeping an optimistic position until a guessed timeout, which previously masked advancing audio snapshots after a seek.

Three update strategies were compared: retaining an optimistic target until a later snapshot approaches it or a timeout expires (the former implementation, which froze progress after a failed/stale seek); issuing a separate snapshot read after each seek (which adds IPC and still needs ordering against older polls); and returning the worker's post-command snapshot while fencing poll responses that began before the command (chosen). This follows the same authority boundary highlighted in ECHO's published design, where its audio host owns output-clock position and the UI only displays and controls playback; it does not adopt ECHO's Electron/host architecture. MusicPlayer2 is useful as a product-level local player reference, but its public documentation does not define this worker/Renderer snapshot contract. No third-party implementation code was copied.

Rodio's version-locked `0.22.2` API documents total duration as optional and seeking as fallible ([`Source`](https://docs.rs/rodio/0.22.2/rodio/source/trait.Source.html)); browser range controls provide distinct continuous `input` and committed `change` events ([MDN input](https://developer.mozilla.org/en-US/docs/Web/API/Element/input_event), [MDN change](https://developer.mozilla.org/en-US/docs/Web/API/HTMLElement/change_event)). ECHO describes an LGPL-3.0-only host-centered audio path and output-clock authority ([official README](https://github.com/Moekotori/ECHO)); MusicPlayer2's repository is GPL-3.0 ([official repository](https://github.com/zhongyang219/MusicPlayer2)). Their architecture and product behavior were consulted as references only; no code was copied.
