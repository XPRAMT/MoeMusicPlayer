# Main-window background sources

The main-window background is a saved source choice (solid color, copied image, recursive slideshow, current track artwork, or Windows wallpaper image). For non-solid modes, blur, image opacity, and zoom remain separate saved appearance settings. Zoom ranges from 0% to 10%, defaults to 3%, and applies to the main-window backdrop; the Now Playing backdrop keeps its own 3% baseline. System wallpaper is read as an image instead of making the application window transparent, because transparency would reveal whichever window is underneath and does not guarantee that the desktop wallpaper is visible; Android wallpaper access is deferred.
