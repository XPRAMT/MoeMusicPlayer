## 繁體中文

距離 v26.10.25 的變更。

**字型**
- 新增字型選擇：主介面（設定 → 主介面「字型」）、播放頁歌詞、工作列歌詞（Windows）與浮動歌詞（Windows、Android）可各自選擇系統已安裝的字型，選了立即套用。歌詞設定頁的字型放在「字體與大小」第一項。
- 字型清單依作業系統的地區分成「繁體中文／簡體中文／日文／英文」（例如在台灣繁體中文排第一），字型名稱以地區的語言顯示，每一列都以該字型本身繪製。可以搜尋、點分組標題快速跳到該組，也能用方向鍵與 Enter 選擇。
- 清單第一列標出實際使用的預設字型，例如「預設（微軟正黑體）」。
- 第一次開啟字型清單時會先讀取所有字型（顯示「讀取字型中…」），之後開啟立即顯示，新安裝或移除的字型在背景更新。啟動 App 時不掃描字型。
- 無法顯示一般文字的字型（例如只有擴充字集、造字或只有注音／假名的字型）不會列出。

**歌詞與歌曲檔案**
- 歌詞每一句會使用檔案本身的結束時間（SRT、ASS、yrc、QRC，以及增強型 LRC 行尾的時間）：「連續」動畫依這個時間滑動；有結束時間但沒有逐字時間的句子，在播放頁以及動畫「無」的工作列歌詞與浮動歌詞也會以卡拉 OK 方式整句掃過。
- 「導入使用中歌詞」會保留每一句的結束時間。
- 「移除歌詞」改名為「不再搜尋」：只停止這首歌的自動線上搜尋，歌曲檔案自己的內嵌歌詞或同名歌詞檔仍會照常顯示。
- 修正同步曲庫之後才修改的內嵌歌詞或同名歌詞檔仍顯示舊內容（或沒有歌詞），要重新同步才更新；現在每次都讀取檔案當下的歌詞。
- 開始播放一首歌時會在背景檢查檔案是否已變更，有變更就重新讀取標籤並更新清單、封面與歌詞，不會中斷播放。

**Android**
- 修正 Sony Xperia 等部分裝置播放 FLAC（尤其是 24-bit 高解析 FLAC）沒有聲音：FLAC 改由 App 內建的解碼器播放，本機與遠端歌曲都適用。
- 修正橫向使用且系統導覽列在側邊時，播放頁頂欄的按鈕被裁掉；睡眠定時、收藏、音量面板、提示文字與播放通知也不再被系統列遮住。

## English

Changes since v26.10.25.

**Fonts**
- New font choice: the interface (Settings → 主介面, 字型), Now Playing lyrics, taskbar lyrics (Windows) and floating lyrics (Windows and Android) can each use any installed system font, applied as soon as you pick it. On the lyrics settings tabs the font is the first item of 字體與大小.
- The font list is grouped by your operating system's region into 繁體中文 / 簡體中文 / 日文 / 英文 (for example Traditional Chinese first in Taiwan), font names are shown in the region's language, and every row is drawn in its own font. You can search, tap a group heading to jump to a group, or choose with the arrow keys and Enter.
- The first row names the default font actually used, for example 預設（微軟正黑體）.
- The first time the font list opens it reads every font first (showing 讀取字型中…); later it opens at once and newly installed or removed fonts are updated in the background. Fonts are never scanned at app start.
- Fonts that cannot show ordinary text (for example extension-only, private character or Bopomofo/kana-only fonts) are not listed.

**Lyrics and song files**
- Each lyric line now uses the file's own end time (SRT, ASS, yrc, QRC and the closing time of enhanced LRC lines): the 連續 animation glides by it, and a line with an end time but no word times is swept karaoke style as a whole on Now Playing and in taskbar and floating lyrics with animation 無.
- 導入使用中歌詞 keeps each line's end time.
- 移除歌詞 is renamed 不再搜尋: it only stops the automatic online search for the song, and the song file's own embedded lyrics or same-name lyrics file still show.
- Fixed embedded lyrics or a same-name lyrics file edited after the last library sync still showing the old lyrics (or none) until the next sync; the lyrics are now read from the file every time.
- When a song starts, its file is checked in the background; if it changed, its tags are read again and the list, cover and lyrics are updated without interrupting playback.

**Android**
- Fixed FLAC, especially 24-bit hi-res FLAC, playing no sound on some devices such as Sony Xperia: FLAC is now played by the app's own decoder, for local and remote songs.
- Fixed the Now Playing top bar buttons being cut off in landscape when the system navigation bar is at the side; the sleep timer, favourite and volume popovers, tooltips and playback notices are no longer covered by the system bars either.
