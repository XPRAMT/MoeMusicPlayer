## 繁體中文

距離 v26.10.24 的變更。

**逐字歌詞（卡拉 OK）**
- 支援逐字歌詞。播放頁目前這一句會以主色由左到右掃過，已唱的部分維持主色到換句為止。
- 工作列歌詞（Windows）與浮動歌詞（Windows、Android）也支援逐字歌詞：動畫「無」時以卡拉 OK 方式顯示；「連續」時依整句的開始與結束時間平順滑動。
- 線上搜尋 QQ 音樂歌詞時，若社群逐字歌詞庫（AMLL TTML DB）有這首歌，會多一個逐字歌詞候選，與同一首的行級歌詞同分時排在前面。只在你搜尋時才連線。
- 網易雲音樂的歌詞改為取得逐字版本，譯文與羅馬音會對齊到每一句。
- 「導入使用中歌詞」遇到逐字歌詞時，以增強型 LRC 寫入，保留每個字的時間。

**歌詞格式與來源**
- 新增支援增強型 LRC、網易雲 yrc、明文 QRC、SRT 與 ASS 字幕。內嵌歌詞與同名旁檔都依內容自動辨識格式，旁檔可為 `.lrc`、`.qrc`、`.ass`、`.srt`。
- 本機歌詞的順序改為：歌曲內嵌歌詞優先，其次才是同名旁檔，最後是線上歌詞。
- 同一時間的多行歌詞（LRC 同時間戳行、SRT 多行、ASS 同時間事件）會依內容判斷是譯文還是羅馬音，播放頁依「原文 → 羅馬音 → 譯文」顯示。
- 歌詞候選清單不再顯示「高信心／中信心／低信心」標籤。

**歌詞設定**
- 「透明度」與「非目前歌詞透明度」改為每個設定頁各自的「主要透明度」與「次要透明度」（1–100%，預設 100% 與 50%）。播放頁：目前這一句用主要透明度，其他句用次要透明度。舊的透明度設定不會沿用，更新後請重新調整。
- 新增「字體粗細」（100–1000，預設 500），播放頁、工作列歌詞、浮動歌詞各自設定；譯文與羅馬音比原文略細。
- 設定頁的「外觀」分組改名為「文字效果」；分頁「一般」改名為「播放頁」。
- 播放頁的「同步歌詞延遲」改名為「歌詞同步」，數值方向改為：歌詞比歌聲早就調成負值、比歌聲晚就調成正值。已儲存的調整效果不變，只是顯示的正負號相反。

**工作列歌詞與浮動歌詞**
- 「連續」動畫改用一張固定在歌詞區的透明度遮罩（實驗性）：中央以主要透明度顯示，往兩側漸變到次要透明度，邊緣完全透明。
- 「連續」動畫中最後一句的移動時間依文字寬度估計，英文等半形文字不再移動得過慢。
- 「連續」動畫中沒有逐字時間的句子，後面接長間奏時不再拖滿整段間奏：全形字每字最多 1 秒、半形字每字最多 0.5 秒內走完這一句，剩下的時間再慢慢移到下一句。
- 浮動歌詞的位置改以歌詞區左上角記錄，開啟或關閉「顯示譯文」時第一行不會移動。舊版存的位置不轉換，更新後面板可能需要重新擺放一次。
- 修正 Windows 浮動歌詞重新開啟或重新啟動 App 後沒有回到上次儲存的位置。

**Android**
- 浮動歌詞改用 OpenGL ES 在專用執行緒繪製，跟隨螢幕更新率，CPU 用量更低。
- 浮動歌詞支援「字體粗細」。

**播放與遠端伺服器**
- 切換歌曲時先確認新歌曲能開啟才切換；準備期間目前的音樂照常播放。點選的歌曲無法播放時，畫面維持原狀並顯示自動消失的通知（「伺服器無法連線」或「無法播放這首歌」），不會自動跳到下一首。
- 歌曲自然播完時，若下一首無法播放，會依播放順序嘗試後面的歌曲；連不上的伺服器上的其他歌曲本輪直接略過。
- 連續點選多首歌曲時以最後一次的選擇為準，不會因為前一個指令還在處理而被忽略。
- 遠端歌曲整首已在磁碟快取中時，直接從快取播放、不需要連線，伺服器關閉時也能播放。
- 伺服器連不上時，不再拖慢本機歌曲的封面、清單與播放操作，並更快顯示「伺服器無法連線」。

**播放頁**
- 放大的封面停止操作後以原圖解析度重畫，保持清晰；Android 上雙指縮放與平移時也不會變模糊。
- 縮放封面時歌詞不再每一步都重新排版，停止縮放後一次排好，縮放更流暢。
- 播放列進度條的動畫完全由 GPU 合成，降低 CPU 用量。

**介面**
- 左側搜尋框改為跟著導覽項目一起捲動，MOE 標誌與「設定」維持固定。
- 鍵盤焦點框統一為 1px 的主色細框；修正曲目清單用鍵盤選取時出現黑色粗框。

**歌曲資訊**
- 修改時間與建立時間顯示到秒；只有在檔案時間可能沒有時區的儲存裝置（例如 FAT／exFAT、SD 卡、USB 隨身碟）才加上「(UTC+8)」。
- 修正 Windows 上儲存本機歌曲的標籤後，檔案的建立時間被改成儲存當下的時間。
- 修正「導入使用中歌詞」後再修改歌詞內容才儲存時，歌詞同步的調整沒有歸零，造成調整被套用兩次。

## English

Changes since v26.10.24.

**Word-timed lyrics (karaoke)**
- Word-timed lyrics are supported. On Now Playing the current line is swept from left to right in the accent colour, and the sung part stays in the accent colour until the line changes.
- Taskbar lyrics (Windows) and floating lyrics (Windows and Android) support word-timed lyrics too: with animation 無 they are shown karaoke style; with 連續 they glide smoothly by each line's start and end.
- When you search QQ Music lyrics online and the community word-timed lyrics database (AMLL TTML DB) has the song, an extra word-timed candidate is offered, ranked ahead of the line-timed one for the same song when they score the same. It connects only when you search.
- NetEase Cloud Music lyrics are now fetched word-timed, with translation and romanization aligned to each line.
- 導入使用中歌詞 writes word-timed lyrics as enhanced LRC, keeping each word's time.

**Lyric formats and sources**
- Enhanced LRC, NetEase yrc, plain-text QRC, SRT and ASS subtitles are supported. Embedded lyrics and same-name sidecar files are recognised by their content; sidecars can be `.lrc`, `.qrc`, `.ass` or `.srt`.
- Local lyrics now come in this order: lyrics embedded in the song first, then the same-name sidecar, then online lyrics.
- Extra lines at the same time (same-timestamp LRC lines, multi-line SRT cues, simultaneous ASS events) are classified as translation or romanization by their content, and Now Playing shows original → romanization → translation.
- The lyrics candidate list no longer shows the high/medium/low confidence label.

**Lyrics settings**
- 透明度 and 非目前歌詞透明度 are replaced by 主要透明度 and 次要透明度 on each settings tab (1–100%, defaults 100% and 50%). On Now Playing the current line uses the main opacity and the other lines the secondary one. The old opacity settings are not carried over, so set them again after updating.
- New 字體粗細 (font weight, 100–1000, default 500), set separately for Now Playing, taskbar lyrics and floating lyrics; translation and romanization are slightly lighter than the original.
- The settings group 外觀 is renamed 文字效果, and the tab 一般 is renamed 播放頁.
- On Now Playing, 同步歌詞延遲 is renamed 歌詞同步 and its sign is flipped: if the lyrics come before the singing, set a negative value; if they come after, set a positive one. Saved adjustments keep their effect; only the shown sign is reversed.

**Taskbar and floating lyrics**
- The 連續 animation now uses one opacity mask fixed to the lyric area (experimental): the centre is shown at the main opacity, fading to the secondary opacity towards both sides and fully transparent at the edges.
- In the 連續 animation the last line's glide time is estimated from the text width, so half-width text such as English no longer moves too slowly.
- In the 連續 animation a line without word times no longer stretches across a long interlude after it: it finishes within 1 s per full-width character and 0.5 s per half-width character, and the rest of the time glides to the next line.
- The floating lyrics position is now saved as the lyric area's top-left corner, so turning 顯示譯文 on or off never moves the first line. Positions saved by older versions are not converted, so you may need to place the panel again once after updating.
- Fixed Windows floating lyrics not returning to the saved position after reopening them or restarting the app.

**Android**
- Floating lyrics are drawn with OpenGL ES on a dedicated thread, following the display's refresh rate with lower CPU use.
- Floating lyrics support 字體粗細.

**Playback and remote servers**
- Switching songs now checks that the new song opens before switching, and the current music keeps playing meanwhile. If a song you pick cannot be played, nothing changes and an auto-dismissing notice says 伺服器無法連線 (server unreachable) or 無法播放這首歌 (this song cannot be played); playback does not jump to the next song.
- When a song ends and the next one cannot be played, the following songs are tried in queue order; other songs on an unreachable server are skipped for that pass.
- When you pick several songs in a row, the last pick wins; it is no longer ignored because an earlier command is still running.
- A remote song that is fully in the disk cache plays from the cache without connecting, even when the server is off.
- An unreachable server no longer slows down local songs' covers, lists and playback controls, and 伺服器無法連線 is shown sooner.

**Now Playing**
- A zoomed-in cover is redrawn from the full-resolution image once you stop, so it stays sharp; on Android it also stays sharp during pinch and two-finger pan.
- While you zoom the cover, the lyrics are no longer re-laid out at every step; they settle once you stop, so zooming is smoother.
- The playback bar's progress animation runs entirely on the GPU compositor, lowering CPU use.

**Interface**
- The search field on the left now scrolls with the navigation items; the MOE logo and 設定 stay in place.
- Keyboard focus rings are now one thin 1px accent-coloured outline everywhere; fixed the thick black frame on track list rows selected with the keyboard.

**Song details**
- Modified and created times show seconds; "(UTC+8)" is added only on storage whose file times may have no time zone (for example FAT/exFAT, SD cards and USB drives).
- Fixed saving a local song's tags on Windows changing the file's creation time to the time of the save.
- Fixed the 歌詞同步 adjustment not being reset when you used 導入使用中歌詞, then edited the lyrics before saving, so the adjustment was applied twice.
