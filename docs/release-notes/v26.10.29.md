## 繁體中文

距離 v26.10.27 的變更。

**Android 音訊輸出**
- 新增輸出裝置選擇：可選「系統預設」或指定一台裝置；拔除後改由系統預設播放，重新接上時自動切回。整張裝置卡片都可以點選。
- 每台裝置會顯示播放路徑與格式，和 Windows 同一種寫法，包含「系統混音」這一步、藍牙編碼（例如 LDAC 與其位元率模式）。
- 新增「輸出模式」：「共享」或「獨佔優先」。選獨佔優先時，USB DAC 由本程式獨佔輸出，以歌曲原本的格式位元完美播放；第一次使用會直接跳出系統的 USB 權限詢問。
- 新增「DSD 直通（獨佔模式）」：本地與遠端的 DSF、WavPack DSD 可原生直通到支援的 USB DAC；無法直通時會顯示原因並改以 PCM 播放。
- 新增「藍牙取樣率跟隨曲目」：換歌時把藍牙編碼的取樣率改成最接近這首歌的值（需要 root 或 Shizuku，預設關閉）。
- 新增「自訂藍牙編碼順序」：長按拖曳排列藍牙編碼的優先順序（需要 root 或 Shizuku）。
- 有 root 或 Shizuku 時，「系統取樣率」會顯示這首歌實際的系統混音取樣率。這三項功能共用一個授權說明面板，取得權限後面板自動關閉，「前往授權」入口也會隱藏。
- 播放設定頁分成「模式」、「裝置」、「藍牙」、「DSD」幾個區塊；「獨佔」改名為「獨佔優先」。

**Android 開啟方式**
- 可以從檔案管理員、瀏覽器下載或通訊軟體用本程式開啟音訊檔；會以該檔案所在資料夾的歌曲作為播放佇列開始播放，程式已在執行時也一樣。

**Windows 音訊**
- 輸出裝置會列出每台裝置實際能開啟的取樣率。
- 修正 AIFF、MP1、MP2 檔案能讀到標籤卻無法播放。

**格式、標籤與歌詞**
- 「格式」一律顯示音訊編碼而不是容器（例如 ALAC、APE），只掃描能讀取並播放的格式。
- 所有格式（包含 DSF、APE 系列）的內嵌封面與內嵌歌詞，在本地與遠端、Windows 與 Android 都能讀到；修正 Android 上本地 DSF 沒有封面。
- 多位演出者的值全部保留，曲目與光碟編號支援「n/m」寫法，ALAC、AIFF 的位元深度正確顯示。更新後會自動重新讀取一次歌曲資料。
- Android 通知的封面與曲目資訊更完整。

**播放**
- 緩衝時進度條的圓點會閃爍提示；串流卡住時播放時間會停住，不再往回跳。
- 修正排序過的播放清單建立的播放佇列無法保存，重開後沒有恢復。

**介面**
- 重新開啟程式時會回到上次關閉時所在的頁面（Windows 與 Android）。
- 專輯詳細頁：封面旁的資訊會隨捲動收合連續重新排版，演出者清單以整行截斷，收合動畫更順；封面只在開啟專輯時掃描一次，離開頁面即停止。
- 封面縮放：用滑鼠拖曳縮小的封面可以再次滑動切換，只有放大時才是平移；縮放後畫面更清晰，還原時不再殘留第二張封面。
- 列表：標題列與分組列不會被選取文字，欄寬拖曳範圍更好抓；「來源」欄自動寬度並置中；長文字省略的計算更快。
- 浮動歌詞的位置改以螢幕比例保存，換解析度或螢幕後位置一致；位置、鎖定與每首歌的歌詞延遲都會隨設定與資料庫保存，包含在備份裡。

## English

Changes since v26.10.27.

**Android audio output**
- New output device choice: pick 「系統預設」 (system default) or one device; when it is unplugged the system default plays, and playback switches back when it is reconnected. The whole device card is the switch.
- Each device shows its playback path and formats in the same style as Windows, including the 「系統混音」 (system mixer) step and the Bluetooth codec (for example LDAC and its bitrate mode).
- New 「輸出模式」 (output mode): 「共享」 (shared) or 「獨佔優先」 (prefer exclusive). With prefer exclusive a USB DAC is driven exclusively by the app, bit-perfect in the song's own format; the first use asks the system USB permission dialog directly.
- New 「DSD 直通（獨佔模式）」 (DSD passthrough): local and remote DSF and WavPack DSD play natively on a supporting USB DAC; when passthrough is not possible the reason is shown and the track plays as PCM.
- New 「藍牙取樣率跟隨曲目」: on each track change the Bluetooth codec sample rate is set to the one closest to the track (needs root or Shizuku, off by default).
- New 「自訂藍牙編碼順序」: long-press and drag to order the Bluetooth codecs by priority (needs root or Shizuku).
- With root or Shizuku, 「系統取樣率」 shows the real system mixer sample rate of the playing track. The three features share one permission panel, which closes by itself once permission is available, and the 「前往授權」 entries are then hidden.
- The playback settings page is split into 「模式」, 「裝置」, 「藍牙」 and 「DSD」 sections; 「獨佔」 is renamed 「獨佔優先」.

**Android open with**
- Audio files can be opened with the app from a file manager, browser downloads or a messaging app; playback starts with the songs of that file's folder as the queue, also when the app is already running.

**Windows audio**
- Output devices list the sample rates each device can actually be opened at.
- Fixed AIFF, MP1 and MP2 files whose tags were readable but which would not play.

**Formats, tags and lyrics**
- 「格式」 always shows the audio codec, not the container (for example ALAC, APE); only formats that can be read and played are scanned.
- Embedded covers and embedded lyrics are read for every format (DSF and the APE family included), local and remote, on Windows and Android; fixed local DSF files showing no cover on Android.
- Every artist value is kept, track and disc numbers written as 「n/m」 are understood, and ALAC and AIFF bit depths show correctly. After updating, song data is re-read once automatically.
- The Android notification shows a more complete cover and track information.

**Playback**
- The progress bar thumb pulses while buffering; when a stream stalls the playback time stops instead of jumping back.
- Fixed play queues built from a sorted playlist not being saved, so they were not restored after a restart.

**Interface**
- The app reopens on the page it was closed on (Windows and Android).
- Album detail page: the info beside the cover re-wraps continuously as it collapses on scroll, the artist list is cut by whole lines, and the collapse is smoother; covers are scanned once when the album is opened and the scan stops when you leave the page.
- Cover zoom: a shrunk cover can be swiped again with a mouse drag, and only an enlarged cover pans; zoomed covers are sharper and no second cover is left behind after restoring.
- Lists: header and group rows no longer select text and the column resize handle is easier to grab; the 「來源」 column sizes itself and is centred; long-text ellipsis is faster.
- Floating lyrics positions are saved as a screen ratio, so they stay in place across resolutions and screens; positions, the lock and each song's lyric delay are saved with the settings and library and included in backups.
