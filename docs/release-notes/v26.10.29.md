## 繁體中文

距離 v26.10.27 的變更。

### 新增

- Android 輸出裝置：可選「系統預設」或指定一台裝置；拔除後改由系統預設播放，重新接上時自動切回。整張裝置卡片都可以點選。
- Android 輸出裝置：每台裝置會顯示播放路徑與格式，和 Windows 同一種寫法，包含「系統混音」這一步、藍牙編碼（例如 LDAC 與其位元率模式）。
- Android「輸出模式」：「共享」或「獨佔優先」。選獨佔優先時，USB DAC 由本程式獨佔輸出，以歌曲原本的格式位元完美播放；第一次使用會直接跳出系統的 USB 權限詢問。
- Android「DSD 直通（獨佔模式）」：本地與遠端的 DSF、WavPack DSD 可原生直通到支援的 USB DAC；無法直通時會顯示原因並改以 PCM 播放。
- Android「藍牙取樣率跟隨曲目」：換歌時把藍牙編碼的取樣率改成最接近這首歌的值（需要 root 或 Shizuku，預設關閉）。
- Android「自訂藍牙編碼順序」：長按拖曳排列藍牙編碼的優先順序（需要 root 或 Shizuku）。
- Android「系統取樣率」：有 root 或 Shizuku 時顯示這首歌實際的系統混音取樣率。這三項功能共用一個授權說明面板，取得權限後面板自動關閉，「前往授權」入口也會隱藏。
- Android 開啟方式：可以從檔案管理員、瀏覽器下載或通訊軟體用本程式開啟音訊檔；會以該檔案所在資料夾的歌曲作為播放佇列開始播放，程式已在執行時也一樣。
- Windows 輸出裝置：列出每台裝置實際能開啟的取樣率。
- 重新開啟程式時會回到上次關閉時所在的頁面（Windows 與 Android）。
- 緩衝時進度條的圓點會閃爍提示。

### 改進

- 播放設定頁分成「模式」、「裝置」、「藍牙」、「DSD」幾個區塊；「獨佔」改名為「獨佔優先」。
- 「格式」一律顯示音訊編碼而不是容器（例如 ALAC、APE），只掃描能讀取並播放的格式。
- 所有格式（包含 DSF、APE 系列）的內嵌封面與內嵌歌詞，在本地與遠端、Windows 與 Android 都能讀到。
- 多位演出者的值全部保留，曲目與光碟編號支援「n/m」寫法，ALAC、AIFF 的位元深度正確顯示。更新後會自動重新讀取一次歌曲資料。
- Android 通知的封面與曲目資訊更完整。
- 專輯詳細頁：封面旁的資訊會隨捲動收合連續重新排版，演出者清單以整行截斷；封面只在開啟專輯時掃描一次，離開頁面即停止。
- 縮放中的封面更清晰。
- 播放頁歌詞的跳轉按鈕透明度改為跟隨「次要透明度」。
- 底欄上緣的時間軸有自己的一條區域，不再蓋住上方內容（例如寬列表的水平捲軸）。
- 列表：標題列與分組列不會被選取文字，欄寬拖曳範圍更好抓；「來源」欄自動寬度並置中；長文字省略的計算更快。
- 浮動歌詞的位置改以螢幕比例保存，換解析度或螢幕後位置一致。
- 各面板的顯示偏好、Android 浮動歌詞的位置與鎖定改存在設定中，每首歌的歌詞延遲改存在曲庫中；「匯出備份」時勾選「設定」與「曲庫」就會一起備份。舊的值在更新後會自動搬過去一次。

### 修復

- Windows：AIFF、MP1、MP2 檔案能讀到標籤卻無法播放。
- Android 上本地 DSF 沒有封面。
- 遠端串流等待資料時，進度條與歌詞每隔半秒往回跳；現在會停在原位，資料到了再繼續。
- 排序過的播放清單建立的播放佇列無法保存，重開後沒有恢復。
- Android 上快速滑動專輯詳細頁時，封面與資訊的收合會跳格不連續。
- 用滑鼠拖曳縮小的封面無法滑動切換歌曲；現在只有放大時拖曳才是平移。
- 封面滑動或還原後畫面上殘留一張錯位的第二張封面。

## English

Changes since v26.10.27.

### New

- Android output devices: pick "System default" or one device; when it is unplugged the system default plays, and playback switches back when it is reconnected. The whole device card is the switch.
- Android output devices: each device shows its playback path and formats in the same style as Windows, including the system mixer step and the Bluetooth codec (for example LDAC and its bitrate mode).
- Android "Output mode": "Shared" or "Prefer exclusive". With "Prefer exclusive" a USB DAC is driven exclusively by the app, bit-perfect in the song's own format; the first use asks the system USB permission dialog directly.
- Android "DSD passthrough (exclusive mode)": local and remote DSF and WavPack DSD play natively on a supporting USB DAC; when passthrough is not possible the reason is shown and the track plays as PCM.
- Android "Match Bluetooth sample rate to the track": on each track change the Bluetooth codec sample rate is set to the one closest to the track (needs root or Shizuku, off by default).
- Android "Custom Bluetooth codec order": long-press and drag to order the Bluetooth codecs by priority (needs root or Shizuku).
- Android "System sample rate": with root or Shizuku it shows the real system mixer sample rate of the playing track. The three features share one permission panel, which closes by itself once permission is available, and the "Go to permission" entries are then hidden.
- Android open with: audio files can be opened with the app from a file manager, browser downloads or a messaging app; playback starts with the songs of that file's folder as the queue, also when the app is already running.
- Windows output devices: the sample rates each device can actually be opened at are listed.
- The app reopens on the page it was closed on (Windows and Android).
- The progress bar thumb pulses while buffering.

### Improved

- The playback settings page is split into "Mode", "Devices", "Bluetooth" and "DSD" sections; "Exclusive" is renamed "Prefer exclusive".
- "Format" always shows the audio codec, not the container (for example ALAC, APE); only formats that can be read and played are scanned.
- Embedded covers and embedded lyrics are read for every format (DSF and the APE family included), local and remote, on Windows and Android.
- Every artist value is kept, track and disc numbers written as "n/m" are understood, and ALAC and AIFF bit depths show correctly. After updating, song data is re-read once automatically.
- The Android notification shows a more complete cover and track information.
- Album detail page: the info beside the cover re-wraps continuously as it collapses on scroll and the artist list is cut by whole lines; covers are scanned once when the album is opened and the scan stops when you leave the page.
- Zoomed covers are sharper.
- The Now Playing lyrics seek button now follows "Secondary opacity".
- The timeline on the top edge of the dock has its own band and no longer covers the content above it (for example the horizontal scrollbar of wide lists).
- Lists: header and group rows no longer select text and the column resize handle is easier to grab; the "Source" column sizes itself and is centred; long-text ellipsis is faster.
- Floating lyrics positions are saved as a screen ratio, so they stay in place across resolutions and screens.
- The panel display preferences and the Android floating lyrics position and lock are now kept in the settings, and each song's lyric delay in the library; "Export backup" with "Settings" and "Library" ticked backs them up. Old values are moved over once after updating.

### Fixed

- Windows: AIFF, MP1 and MP2 files whose tags were readable but which would not play.
- Local DSF files showing no cover on Android.
- The progress bar and lyrics jumping back every half second while a remote stream waits for data; they now hold still and continue once data arrives.
- Play queues built from a sorted playlist not being saved, so they were not restored after a restart.
- The album detail collapse skipping frames during a fast fling on Android.
- A shrunk cover ignoring mouse drags, so it could not be swiped to change songs; a drag now pans only an enlarged cover.
- A displaced second cover staying on screen after a swipe or restore.
