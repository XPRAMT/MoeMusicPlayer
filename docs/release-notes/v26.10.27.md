## 繁體中文

距離 v26.10.26 的變更。

**播放頁歌詞**
- 新增捲動歌詞跳轉：捲動同步歌詞後，畫面中央那一句（不是目前句時）左邊會出現播放按鈕，按下就從那一句開始播放。按鈕大小跟著原文字體大小，有譯文或羅馬拼音時置中在整組歌詞旁邊，不會蓋到文字。
- 捲動後 1.5 秒內換句不會把畫面拉回，之後下一次換句才回到目前句。

**播放佇列**
- 修正頂欄選「本地」或「雲端」時，從列表點歌建立的播放佇列仍混入另一邊的歌曲（Android），下一首可能跳到不該播的歌。
- 從任何列表點歌時，播放佇列只會放入畫面上看得到的歌曲，順序也和畫面相同：修正演出者頁的佇列可能多出或少了歌曲，以及播放清單頁的佇列沒有照目前的排序。
- 點的歌曲不在目前列表中時（例如列表剛更新），仍會照常播放。
- 播放中切換「本地／雲端」不會改變目前的播放佇列；播放佇列頁會完整列出佇列，頂欄不再顯示「本地／雲端」切換。

**播放**
- 修正把進度拖到歌曲最後時出現「無法移動到指定播放位置」並停止播放。現在拖到最後就當作播完：播放中接著播下一首，暫停中換到下一首並停在開頭、保持暫停。

## English

Changes since v26.10.26.

**Now Playing lyrics**
- New scroll-to-seek: after you scroll the synced lyrics, the line at the centre of the view (when it isn't the current line) shows a play button on its left; press it to play from that line. The button follows the original-text font size, is centred beside the whole line group when there is a translation or romanization, and never covers the text.
- For 1.5 seconds after you scroll, a line change does not pull the view back; the next line change after that returns to the current line.

**Play queue**
- Fixed queues built by tapping a song in a list still mixing in songs from the other side when the top bar was set to 本地 or 雲端 (Android), so the next track could be one that should not play.
- Tapping a song in any list now queues exactly the songs the list shows, in the order shown: fixed the artist page queue gaining or missing songs, and the playlist page queue ignoring the current sort.
- A tapped song that is not in the current list (for example right after the list changed) still plays.
- Switching 本地／雲端 during playback no longer changes the current queue; the play queue page lists the whole queue and no longer shows the 本地／雲端 switch.

**Playback**
- Fixed dragging the progress bar to the very end of a song showing 「無法移動到指定播放位置」 and stopping playback. Dragging to the end now counts as the song finishing: while playing the next song plays, and while paused the player moves to the next song at its start and stays paused.
